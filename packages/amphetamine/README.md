# Amphetamine

Shows the current Amphetamine session in your bar: Off, Awake, or the minutes remaining. Click it to keep your Mac awake for one hour, keep it awake indefinitely, or end the current session.

Install and open the Amphetamine app before using this package. Allow StableBar to control Amphetamine when macOS asks for Automation access.

Starting a session replaces the current session, including a trigger session. New sessions use Amphetamine's display-sleep preference. Ending a trigger session does not disable its trigger, so it may restart.

The widget checks the session every five seconds. It does not change Amphetamine's closed-display settings; configure those in Amphetamine if needed.
